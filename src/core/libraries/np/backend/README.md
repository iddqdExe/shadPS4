# np/backend (M4, generic)

Replacement NP backend for Matching2 rooms and signaling on top of p2p_transport (host-owned
rooms, local sign-in, per-request timeouts, real ORBIS error codes). Game-agnostic; candidate
for upstreaming. Filled in stage 1. See the BB Co-op spec §8.2 in the parent repository.
