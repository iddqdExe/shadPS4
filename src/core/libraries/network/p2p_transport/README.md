# p2p_transport (M3, generic)

Generic UDP transport for P2P sockets: single socket, vport multiplexing, reliable channels,
keepalive, roaming, encryption. Game-agnostic; candidate for upstreaming. Filled in stage 1.
See the BB Co-op spec §8.1 in the parent repository.
